# مترجم حبابی صفحه (Screen Bubble Translator)

برنامهٔ اندروید: یک حباب شناور روی صفحه؛ با لمس آن، از صفحه عکس گرفته می‌شود، به مدل بینایی ChatGPT / Gemini / Claude (با کلید API خودت) فرستاده می‌شود و ترجمهٔ فارسی ⇄ انگلیسی روی همان متن‌ها نمایش داده می‌شود.

- مدل آزاد است: هر اسم مدلی را بنویس، یا لیست مدل‌های سرویس را بگیر و هر کدام را تست کن (فعال/غیرفعال).
- جهت ترجمه: خودکار، فارسی←انگلیسی، یا انگلیسی←فارسی.
- جای ترجمه‌ها را خود مدل تخمین می‌زند؛ ممکن است کمی جابه‌جا باشد. متنی که مختصاتش نیامد در پنل پایین صفحه نشان داده می‌شود.
- چرخش صفحه: بعد از چرخاندن، حباب را یک بار متوقف و دوباره شروع کن.

## ساخت
هر پوش روی شاخهٔ `bubble-translate` در GitHub Actions یک APK دیباگ می‌سازد (Artifact با نام `app-debug`).
پوش روی شاخهٔ `release-bubble` علاوه بر آن یک pre-release با APK منتشر می‌کند.
